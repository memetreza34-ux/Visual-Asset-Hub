# Videos

Alle Dokumentationsvideos liegen hier sichtbar nach Kategorie und Thema sortiert.

```text
videos/
├── umweltgeschichte/
├── geschichte/
├── technik/
├── wissenschaft/
├── wirtschaft/
├── geopolitik/
└── sonstiges/
```

Innerhalb einer Kategorie bekommt jedes Thema einen nummerierten Projektordner:

```text
001-thema/
├── 01-SCRIPT/
├── 02-AUDIO/
├── 03-VISUALS/
├── 04-SOURCES/
├── 05-PROJECT/
└── 06-EXPORT/
```

`documentary-registry/` bleibt die zentrale Themenliste und verhindert Wiederholungen.
