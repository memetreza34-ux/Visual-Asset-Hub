# Vorschauen

Dieser Ordner enthält leichte, webtaugliche Vorschauen für die Suchoberfläche.

Empfohlene Formate:

- Bilder: WebP oder JPEG
- transparente Grafiken: WebP oder PNG
- Videos: bevorzugt ein repräsentatives Standbild; später optional kurze WebM-Vorschau

Empfohlener Name:

```text
{asset-id-lowercase}.webp
```

Beispiel:

```text
vah-a1b2c3d4.webp
```

Vorschauen ersetzen niemals das Original und dürfen keine anderen Nutzungsrechte als das zugehörige Asset erhalten.
